# Balcones League

Aplicación privada del grupo Balcones League.

- Web/PWA: `index.html`
- Android: `android-app/`
- Backend compartido: Supabase
- Paquete Android: `com.balconesleague.app`

La aplicación Android envuelve la misma interfaz HTML en un WebView. Los resultados y estadísticas se sincronizan mediante Supabase.

El APK generado automáticamente se publica en `download/Balcones-League.apk`.
